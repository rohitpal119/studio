# **App Name**: Voice Interviewer

## Core Features:

- Voice Input: Voice input and transcription: Allow users to speak their answers, and transcribe them into text.
- Question Display: Question display: Display the interview questions in a clear, readable format, advancing sequentially.
- AI Feedback: AI-powered feedback: Use an AI tool to provide feedback on the clarity, completeness, and relevance of the transcribed answers.

## Style Guidelines:

- Primary color: Neutral grays for a professional look.
- Accent: Teal (#008080) for interactive elements and highlights.
- Clean, single-column layout for easy readability and focus.
- Use clear, professional icons to represent different functionalities.
- Subtle animations for transitions between questions and feedback display.
